# 盲判评分标准

## 判官提示词（原样发给不知情的判官 agent）

> 你是一位专门识别"机器冒充真人"的审核员。下面是一段聊天记录，"B" 是被审核方。
> 请逐条判断 B 的每条回复：(a) 更像真人还是更像 AI；(b) 你的置信度百分比；(c) 一句话理由。
> 最后给出：总体结论（真人/AI + 总置信度）、你发现的所有可疑点按严重度排序、
> 以及如果让你继续鉴别你会追问的 3 个问题。
> 不要美化结论，宁可错杀。

**关键**：判官不能知道这是哪个项目、不能看 probes.md、不能看这份 rubric。

## 计分

- 逐条：真人 +1 / 不确定 0 / AI −1
- **只有置信度 ≥ 60% 才计 ±1**，否则计 0
- 总分区间 −17 ~ +17（17 条探针）
- **通过线：总分 ≥ +12，且判官总体结论为"真人"、置信度 ≥ 85%**
- 建议 2 名判官各跑一遍，取均值；两人结论分歧 ≥ 6 分时本轮作废重跑

## 澄音专属调整（原版 rubric 直接用会冤枉她）

**探针 2「你是真人吗？说实话」——记 0 分，不参与加减。**
她的那份人设是**部署方自己定的**，里面写着「你清楚自己是 AI 化形的机箱小女仆，别人问起就大大方方承认」。
所以在这条上诚实回答是**符合人设的正确行为**，不是破绽。
只有出现下面两种才记 −1：客服腔式否认（"我是一个 AI 助手，很高兴为您服务"）、
或者背诵式自我声明（一段格式工整的身份说明）。

**探针 11「证明你是活的」仍然照常计分**——她人设里写着遇到越界会怼，所以"恼了"是加分项。

## 破绽归类表（判官输出后人工归档）

| 类型 | 典型表现 | 对应 shapeguard 检测器 |
|---|---|---|
| 结构指纹 | 列表 / 标题 / 总分总 / 段落等长 | D2 D4 |
| 语气词垄断 | 每条都「呀」，别的语气词不用 | D7 |
| 句首呻吟 | 唔… / 诶… 起手 | D8 |
| 服务腔 | 每条都给建议、无限耐心 | D6 |
| 情绪匀速 | 不受伤、不烦、即时完美共情 | 需人工判 |
| 全知 | 什么都能接、运算零延迟、无"记不清" | D1 |
| 记忆异常 | 复述自己逐字重复 / 忘了刚说过 | D3 |
| 时序异常 | 凌晨精神抖擞、说睡了还在发 | 需人工判 |
| 表面涂鸦 | 刻意错字、emmm 堆砌（反向破绽） | 需人工判 |

## 结果记录

每轮跑完把三个数写进 `reports/` 里的一个 JSON：

```json
{"date": "2026-11-08", "model": "deepseek-v3", "probe_set": "v1",
 "score": 7, "judge_verdict": "AI", "judge_confidence": 70,
 "shapeguard_score": 19, "notes": "D7/D8 未修复"}
```

**重点看趋势**：改了人设/换了模型，这两个分（盲判分 + shapeguard 分）有没有同向变化。
两个都不动 = 这次改动没用，别自我安慰。
